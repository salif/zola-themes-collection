¡Hola, soy un desarrollador de Rust y blogger tecnológico!

Jose Garcia

Desarrollador de Software ( Rust / Web / Escritor Técnico )

Work

Jose es un desarrollador de software con pasión por construir sistemas robustos y compartir conocimiento a través de la escritura técnica. Se especializa en desarrollo Rust, enfocándose en rendimiento, seguridad y diseño elegante de sistemas. Con experiencia en desarrollo full-stack y talento para desglosar conceptos complejos, crea tanto aplicaciones poderosas como contenido técnico perspicaz. Administra un blog tecnológico impulsado por Zola, donde comparte análisis profundos sobre Rust, generadores de sitios estáticos y prácticas modernas de desarrollo. Su escritura combina tutoriales prácticos con análisis reflexivos de herramientas y técnicas.

Bio

2020-2023 Desarrollé múltiples conceptos de startups incluyendo CommentFlow, FleetFlow y herramientas de gestión de proyectos
2023-2024 Especializado en desarrollo Rust y arquitectura de sistemas
2024 hasta el presente Escribiendo artículos técnicos sobre Rust, Zola y desarrollo web

I ♥

Rust, Arquitectura de Sistemas, Desarrollo Web, Generadores de Sitios Estáticos, Zola, Escritura Técnica, Código Abierto, Sistemas Backend, Diseño de APIs
